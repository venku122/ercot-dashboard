# Source and panel capability audit

The JSON companion inventories all 19 supervised families and their consumers. Its revision is the inspected parent revision, not an assertion that this report was present at that revision. Recreate the sanitized inventory with `python3 scripts/audit_source_panels.py --rehearsal artifacts/post-release/source-rehearsal`. The command reads source declarations and credential-presence booleans; it does not read a production environment or make requests. Default enablement is a code fact. Production configured enablement, process liveness and delivery remain **unknown** because deployment read access was not available. A public rendering proves values were served, not which collector or revision served them.

- Credentialed ERCOT forecast families: approved `ERCOT_API_USERNAME`, `ERCOT_API_PASSWORD`, `ERCOT_PUBLIC_API_SUBSCRIPTION_KEY` and `ERCOT_ESR_API_SUBSCRIPTION_KEY` were absent from this execution environment. ERP-08-B live credentialed evidence remains unavailable. Fixture implementation, parser/auth contracts and local delivery isolation are complete separately. Retry bounded inventory/auth/schema checks with approved credentials, then one publication to a new local receiver; never point a rehearsal at production.
- EIA-930 and Henry Hub: approved `EIA_API_KEY` absent. ERP-08-B live evidence remains unavailable. Retry the existing reviewed transport with a real approved key in isolated local delivery after source/schema gates. Do not substitute DEMO_KEY.
- Production configuration/revision: private deployment read access absent; no environment inference from empty panels. ERP-08-A production fields remain unknown. A later read-only deployment inventory should record flags, destination class, revisions and health without exposing environment arrays.
- Excluded resources: resource SOC, current high-resolution ESR without source support, complete TXANS history, unreviewed CAMD/gross-retirement attribution and paid PowerOutage.us stay unavailable. These are not planned activations.

## Later activation and rollback

Human review and explicit deployment authorization remain required. Preserve a coherent receiver backup and the original complete deployment environment. Enable one reviewed family at a time, verify collector-local attempt and delivery, receiver immutable pointer, exact accessible values and public rendering. On failure restore that family flag and its prior environment; do not overwrite unrelated settings or promote failed checkpoints. No such production operation was executed in this campaign.
