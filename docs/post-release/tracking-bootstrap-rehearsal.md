# Deterministic tracking bootstrap rehearsal

`python3 -m unittest discover -s scripts -p test_tracking_bootstrap.py` exercises the actual reconciliation function against a deterministic in-memory issue adapter. The new protocol first reads every state, excludes PRs, rejects duplicate canonical markers and unassessed closed equivalents before writes, then creates only missing markers. A creation timeout triggers an inventory lookup before retry: a persisted marker is reused; if persistence did not occur, execution stops and a subsequent run resumes partial progress. Parent and dependency links are resolved only after all thirteen actual adapter numbers exist.

Body updates replace only an explicitly delimited managed section. Human prefix/suffix bytes, title, state and discussion stay outside the update interface. Unmarked equivalent IDs must be supplied as explicit scope assessments; closed equivalents also require explicit assessment and remain closed. Malformed managed delimiters fail closed. An unchanged rerun creates and edits nothing.
